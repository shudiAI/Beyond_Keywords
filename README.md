# Beyond Keywords

**Investigating Business–Technology Confusion in News Topic Classification**

This project classifies English news headlines as **Business** or **Science & Technology** and compares two approaches:

1. **TF-IDF + Logistic Regression**.
2. **Frozen Sentence-BERT embeddings + Logistic Regression**, using `sentence-transformers/all-MiniLM-L6-v2`.

The comparison covers the full test set and subsets with and without vocabulary overlap. Both models use the original headline only; article descriptions are not model inputs.

The two reviewed lexicons define the overlap analysis and are not used as input features for training the classifiers.

In addition to the main implementation notebook, the project includes a standalone Gradio interface for classifying new headlines using the saved models without retraining.

## Files

The repository contains the following files:

| File | Purpose |
| --- | --- |

The notebooks and four data/lexicon files should remain together in the repository's main directory. The saved model files must remain inside `outputs/artifacts/`.

All supporting Python code is included inside the notebooks. No separate Python source files are required.

## Environment and Setup

Use **Jupyter Notebook or JupyterLab**. Python 3.12 is recommended. CPU execution is supported.

Internet access is required to install packages and download the pretrained SBERT encoder on first use. The supplied AG News data does not need to be downloaded again.

An optional isolated Anaconda environment can be created with:

```bash
conda create -n beyond-keywords python=3.12 -y
conda activate beyond-keywords
```

In a terminal or Anaconda Prompt, install the dependencies:

```bash
python -m pip install "numpy>=2.1,<3" "pandas>=2.2,<3" "scipy>=1.14,<2" "scikit-learn>=1.6,<2" "joblib>=1.4,<2" "torch>=2.6,<3" "sentence-transformers>=6.3,<7" "transformers>=5,<6" "huggingface-hub>=1.3,<3" "matplotlib>=3.10,<4" jupyterlab socksio gradio
```

These ranges describe installation requirements; they are not a record of exact installed versions.

The saved classifiers were developed using scikit-learn 1.6.1. Using the same version is recommended for compatibility when loading the provided `.joblib` files.

Record the versions actually used in the main notebook's Setup section and retain its output for the final submission.

## Run the Main Notebook

1. Download the repository using **Code → Download ZIP** and extract it, or clone it with Git.
2. Open a terminal in the folder containing `Beyond_Keywords.ipynb` and the four data/lexicon files.
3. Start Jupyter:

   ```bash
   python -m jupyter lab
   ```

4. Open `Beyond_Keywords.ipynb`.
5. Set `REBUILD = True` when running the complete pipeline from scratch.
6. Restart the kernel and run every cell in order.
7. Allow the preprocessing, training, and embedding computation to finish. Execution time depends on the available hardware.
8. Review the evaluation tables, integrity checks, and Try it predictions.
9. Save the notebook with its outputs visible.

The main notebook creates an `outputs/` directory containing processed data, trained models, embedding caches, audits, and evaluation results.

Two trained model files, `tfidf.joblib` and `sbert_lr.joblib`, are provided in `outputs/artifacts/` to support the standalone Gradio demo without retraining.

Other generated outputs, including cached embeddings, are excluded from the repository because they can be regenerated by the main notebook.

After a successful complete run, `REBUILD = False` can reuse the generated files. All required outputs must already exist when using this option.

If the required files are missing or if the source data, lexicons, or model settings change, rebuild the pipeline before evaluation. Running with `REBUILD = True` may overwrite previously saved artifacts.

## Notebook Sections

The main notebook is organized into the following sections:

- **Setup:** Imports, configuration, and environment information.
- **Data:** Input validation, duplicate control, and train/development/test preparation.
- **Method 1:** TF-IDF representation and Logistic Regression selection.
- **Method 2:** Frozen Sentence-BERT embeddings and Logistic Regression selection.
- **Results:** Comparison tables, confusion matrices, error analysis, and integrity checks.
- **Try it:** Predictions for new English headlines without retraining.
- **Sources:** Dataset, pretrained encoder, and methodology references.

The separate `Beyond_Keywords_Demo.ipynb` provides an interactive Gradio interface based on the saved classifiers.

## Try It on New Text

The project provides two ways to classify new English news headlines.

### Option 1: Main Notebook

Open `Beyond_Keywords.ipynb` and run the required training and evaluation sections.

Then use the Try it cell to enter an English news headline and select either `tfidf` or `sbert`.

The selected model returns a prediction without retraining.

Empty headlines and invalid model choices return helpful messages.

### Option 2: Gradio Web Interface

The standalone notebook `Beyond_Keywords_Demo.ipynb` provides an interactive web interface for news headline classification.

To run the demo:

1. Install the required dependencies, including Gradio.
2. Ensure that `tfidf.joblib` and `sbert_lr.joblib` are available in `outputs/artifacts/`.
3. Open `Beyond_Keywords_Demo.ipynb` in Jupyter Notebook or JupyterLab.
4. Run the cells in order.
5. Open the Gradio interface using the displayed local link, if it does not appear directly in the notebook.
6. Enter an English news headline.
7. Select the classification model and view the predicted category: **Business** or **Science & Technology**.

The interface loads the previously trained classifiers and uses the same prediction approach as the main notebook.

No model training or fine-tuning is performed in the Gradio demo.

The main training notebook does not need to be executed before launching the demo, provided that the saved model files are available.

Internet access may be required on the first run to download the pinned pretrained SBERT encoder.

## Experimental Protocol

- Retain AG News classes 3 (Business) and 4 (Science & Technology), mapped to labels 0 and 1.
- Use only news headlines as classifier inputs.
- Preserve official test identities and remove conflicting-label duplicate groups and training records linked to test duplicates.
- Split the remaining training data into training and development sets using stratification and seed 42.
- Fit representations and classifiers on training data only.
- Choose model settings using development Macro F1.
- Use the same held-out test examples for both methods.
- Define vocabulary overlap through whole-token or phrase matches from both reviewed lexicons.
- Treat vocabulary overlap as a lexical proxy, not proof of semantic ambiguity.
- Keep the Sentence-BERT encoder frozen; only its downstream Logistic Regression classifier is trained.
- Do not revise lexicons or select model settings using test results.
- Apply the same evaluation procedure to both classifiers.

The original evaluation populations were:

| Dataset Split | Headlines |
| --- | ---: |
| Training | 48,116 |
| Development | 5,347 |
| Test | 3,681 |
| Test vocabulary-overlap subset | 42 |

The reported experimental results should be taken from the completed main notebook run.

The Gradio interface is an additional demonstration tool and does not alter the experimental protocol, trained models, or reported evaluation results.
